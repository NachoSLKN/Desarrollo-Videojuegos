/*Cuando hablamos de path, sabemos que puede ser relativa o absoluta, ejemplo de ruta relativa:
io_file_read("assets/shaders/basic.vert"); en vez de escribir una ruta absoluta: E:\NACHO\ESTUDIO\PROYECTOS\... 
Una ruta relativa se interpreta desde el directorio desde el que ejecutas el programa.
Es muchísimo mejor que poner una ruta absoluta de nuestro PC, porque al subir el proyecto, por ejemplo a Github o sea 
ejecutado por cualquier otra persona, pues obviamente no tendrá acceso a E:\NACHO\...
Y esto es un motor es muy importante ya que io_file_read() se utilizará después para cargar cosas como shaders,
mapas etc. */
