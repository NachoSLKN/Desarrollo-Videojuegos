# Documentación del proyecto

Esta carpeta contiene la documentación de diseño, producción y desarrollo de **El Gigante de Hierro**.

## Documentos principales

- `GDD.md`: visión general del juego.
- `Roadmap.md`: fases y objetivos.
- `Todo.md`: tareas inmediatas.
- `KnownIssues.md`: errores y problemas técnicos.
- `AnimationList.md`: inventario y plan de animaciones.
- `SceneSetup.md`: estructura de escenas.
- `ArtDirection.md`: coherencia visual.
- `TechnicalDesign.md`: arquitectura y sistemas.
- `DevlogPlan.md`: planificación de vídeos.
- `Changelog.md`: historial del proyecto.

La documentación se actualizará junto con cada avance relevante del juego.
