# Lista de animaciones

## Reglas de descarga

Para futuras animaciones de Mixamo:

- Formato: `FBX for Unity`.
- Skin: `Without Skin`, salvo que se necesite una copia completa para pruebas.
- FPS: 30.
- Keyframe Reduction: None.
- `In Place`: activado para locomoción controlada por código.
- Renombrar cada archivo de forma clara antes de importarlo.
