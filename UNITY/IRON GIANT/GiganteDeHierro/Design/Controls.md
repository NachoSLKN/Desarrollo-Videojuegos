# Controles provisionales

## Movimiento

| Acción | Teclado y ratón | Mando |
|---|---|---|
| Mover | WASD | Stick izquierdo |
| Cámara | Ratón | Stick derecho |
| Correr | Shift | Pulsar stick izquierdo |
| Saltar | Espacio | A / X |
| Esquivar | Ctrl | B / Círculo |

## Combate

| Acción | Teclado y ratón | Mando |
|---|---|---|
| Ataque ligero | Clic izquierdo | X / Cuadrado |
| Ataque fuerte | Clic derecho | Y / Triángulo |
| Agarrar | E | RB / R1 |
| Lanzar | E de nuevo | RB / R1 |
| Bloquear | Q | LB / L1 |
| Especial | F | RT / R2 |
| Fijar objetivo | Tab | Stick derecho |

Los controles son provisionales y deberán probarse durante el prototipo.
