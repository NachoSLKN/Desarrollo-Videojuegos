# Shader Graph Fundamentals

![Shader Graph Fundamentals](img/1.png)

Introductory project to **shaders and Unity Shader Graph**, created while learning the fundamentals of shader development through the **GameDev.tv** course *Unity Shader Graph: Create Procedural Shaders & Dynamic FX*.

The goal of this project was to get familiar with Shader Graph and understand how different visual effects can be created and modified inside Unity.

🎓 **Course completed:** [Unity Shader Graph: Create Procedural Shaders & Dynamic FX – Certificate](http://ude.my/UC-2f0e3df2-eaf9-4317-9f68-e4bcbf7d2aef)

## What I Learned

Throughout the project I experimented with:

- Scrolling UVs and Sub Graphs
- Vertex displacement
- Waves, noise and wind
- Fire, smoke and embers
- Triplanar mapping
- Moss accumulation
- Snow and dynamic deformation
- Water, foam and refraction
